# AI Workflow

## Roles

| Role | Model / effort | Use |
|---|---|---|
| Parent / orchestrator | Sol High | Scope, architecture, milestone acceptance |
| Routine or high implementation | Terra High | Normal implementation and complex settled work |
| Read-only advisor | Sol High | High-value architecture judgment, hard ambiguity, key milestone review |

## Rules

- Terra is the normal implementation path.
- Use Sol for meaningful architecture decisions, hard unresolved problems, or key milestone review—not for routine work.
- Do not use the Max tier by default.
- Do not invoke complete Sol Advisor orchestration for process formality alone.
- Keep stable modules frozen unless a stated Demo priority requires a targeted change.
- Focused tests first; full-suite testing is normally milestone work.
